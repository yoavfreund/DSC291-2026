\section{PoissonGAM for Precipitation
Modeling}\label{poissongam-for-precipitation-modeling}}

Demonstrates Poisson GAMs for wet-day count data. \textbf{Poisson}:
count data with mean ≈ variance; \textbf{Log link}: log(μ) = f(x) → μ =
exp(f(x)). Use when: counts, many zeros, mean ≈ var. Avoid for:
continuous outcomes, overdispersion (→ NegativeBinomialGAM), or binary
(→ LogisticGAM).

\subsubsection{Why Deviance Residuals Instead of Raw
Residuals?}\label{why-deviance-residuals-instead-of-raw-residuals}}

For Poisson (and GLMs in general), raw residuals ( r = y - \mu ) are not
ideal for diagnostics because: - \textbf{Heteroscedasticity}: Var(Y) =
μ, so the variance of ( r ) changes with μ - \textbf{Q-Q plots}: Raw
residuals don't approximate normality well - \textbf{Comparability}:
Residuals at different fitted values aren't on a common scale

We use \textbf{deviance residuals} instead.

    \hypertarget{deviance-residual-formula}{%
\subsubsection{Deviance Residual
Formula}\label{deviance-residual-formula}}

\[d_i = \text{sign}(y_i - \mu_i) \cdot \sqrt{2 \left[ y_i \log(y_i/\mu_i) - (y_i - \mu_i) \right]}\]

This is the signed square-root of each observation's contribution to the
deviance. For Poisson, deviance residuals have approximately constant
variance and are closer to normal than raw residuals, making them
suitable for residual plots and Q-Q plots.
